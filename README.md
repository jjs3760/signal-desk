# Signal Desk

매일 오전 8시에 수집을 시작해 오전 8시 30분(Asia/Seoul)에 결과를 게시합니다. 미국·한국 시장의 최근 마감 일봉과 24시간 뉴스를 분석하는 로컬 대시보드입니다.

## 아키텍처

```text
Windows 작업 스케줄러 또는 APScheduler (08:00 수집, 08:30 KST 게시)
  ├─ 네이버증권 → 지수 4개와 업종별 후보 200개 일봉·일별시세 대조 → pandas 보조지표
  └─ 미국 경제지 RSS + 네이버뉴스 경제 기사 → 요약, 매체, 기사 시각과 링크
                       ↓
       Gemini generateContent → Pydantic 및 가격 범위 검증
                       ↓
       public/latest.json 교체 → React 대시보드
```

하루 한 번 생성되는 공통 리포트를 JSON 파일로 제공합니다. 방문자가 늘어도 데이터 공급자나 모델 호출 횟수는 늘지 않습니다. 필요한 서비스는 Python 배치 프로세스와 정적 웹 서버입니다. API 키는 Python 환경에서만 읽습니다.

## 대시보드 실행

프로젝트 루트에서 Node.js 22.12 이상을 사용합니다. PowerShell 예시입니다.

```powershell
npm.cmd ci
npm.cmd run dev
```

터미널의 로컬 주소를 여세요. 기본 화면은 public/latest.json에서 마지막 수집 결과와 생성일을 표시합니다. 파일이 없으면 수집 안내가 나옵니다. 가상 시세는 명시적으로 데모 링크(?demo=1)를 선택했을 때만 표시합니다. 카드 가격은 해당 거래소의 최근 마감 종가이며 통화는 USD 또는 KRW입니다.

## 실제 수집 및 AI 분석

Python 3.11 이상이 필요합니다. 시세만 수집하려면 아래 Gemini 환경 변수 설정 두 줄을 건너뛰세요. AI 추천까지 생성하려면 Gemini API 키와 해당 계정에서 generateContent 및 구조화 출력을 지원하는 모델 ID를 설정하세요.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
$env:GEMINI_API_KEY = Read-Host "Gemini API 키" -MaskInput
$env:GEMINI_MODEL = Read-Host "사용할 Gemini 모델 ID"
.\.venv\Scripts\python.exe backend/pipeline.py
.\.venv\Scripts\python.exe backend/pipeline.py --schedule
```

-MaskInput은 PowerShell 7.1 이상에서 지원합니다. Windows PowerShell 5.1에서는 사용자 환경 변수 편집기에서 GEMINI_API_KEY를 설정한 뒤 새 터미널을 여세요. 한 번 실행하는 명령은 즉시 리포트를 생성합니다. 스케줄 모드는 매일 지정 시각에 실행되며 해당 프로세스와 컴퓨터가 켜져 있어야 합니다. 서버에서는 프로세스 관리자에 등록하거나 시스템 스케줄러로 일회 실행 명령을 호출할 수 있습니다.

## 산출 기준

- 반도체, 조선, 소프트웨어, 방산, 데이터센터, 전력망·전력기기, 원자력, 로봇·자동화, 배터리·에너지저장, 바이오·제약 각 20개 후보를 backend/universe.py에 정의했습니다. 목록은 최근 마감 거래량을 직전 20거래일 평균 거래량으로 나눈 값이 높은 순으로 표시하며, 거래량을 비교할 수 없는 종목은 마지막에 표시합니다. 조선에는 조선소와 엔진·기자재·정비 업체가 포함됩니다. 업종을 선택한 뒤 종목을 누르면 사업 분야, 검증 종가, 기술 지표, 매매 계획, 관련 기사를 볼 수 있습니다. 미국은 뉴욕, 한국은 서울 시간으로 당일 마감 전 일봉을 제외합니다.
- 각 후보의 네이버증권 종목별 뉴스와 미국 상장사의 미국 종목 피드를 별도로 조회합니다. 최근 7일 안의 기사 최대 3건에 원문·요약·발행일을 표시합니다. 시세 검증이 실패해도 후보와 관련 뉴스는 목록에 남습니다.
- Windows에서 프로젝트 가상환경을 만든 뒤 `./backend/register-morning.ps1`로 현재 사용자의 일일 작업 SignalDesk-MorningBrief를 등록할 수 있습니다. 이 방식과 --schedule 중 하나를 사용하세요. 로그인되어 있고 네트워크에 연결된 PC에서 오전 8시에 시작해 오전 8시 30분에 결과를 교체합니다. 수집이 늦으면 완료 즉시 게시하며, 전원이 꺼져 시각을 놓친 경우 다음 실행 가능 시점에 처리합니다. 이미 열린 화면은 매분 최신 파일을 확인합니다.
- 약 1년의 네이버증권 OHLCV로 SMA(5·20·60), Wilder RSI(14), MACD(12·26·9), 볼린저 밴드(20일 평균 ± 모집단 표준편차 2배)를 계산합니다. 종가는 거래소 현지 통화 기준입니다.
- 시장 심리 점수는 네 지수 RSI의 단순평균을 반올림한 자체 지표입니다. 40 미만은 비관, 60 이상은 낙관입니다. 개별 종목 AI 점수는 후보 사이의 상대 평가입니다.
- 미국 MarketWatch·월스트리트저널 RSS의 기사 소개문과 네이버뉴스 경제 섹션의 기사 본문에서 최근 24시간 자료를 수집합니다. 핵심 문장을 추출하고 미국 요약은 Google 번역을 통해 한국어로 표시합니다. 번역 실패 시 영어 요약을 유지합니다. 기사마다 매체·시각·원문 링크를 제공합니다.
- 종목별 상세 분석은 다음 거래일의 20일선 눌림목 시나리오입니다. 매수 기준은 20일 이동평균, 손절 기준은 매수가에서 14일 Wilder ATR의 1.5배를 뺀 값, 매도 기준은 최근 20거래일 고점입니다. ATR은 저장된 일봉에서 전일 종가와 당일 고저가로 계산합니다. 가격은 표시 통화 단위로 반올림한 분석용 기준가이며, 주문 호가 단위나 수수료를 반영하지 않습니다.
- 종가 ≥ 20일선 ≥ 60일선, MACD ≥ 시그널, 비용 전 손익비 ≥ 1.5를 모두 충족하면 조건부 매수 검토, 그 외에는 관망으로 표시합니다. 이 임계값은 백테스트로 성과를 검증하지 않은 전략 가정입니다. 가격 순서가 유효하지 않으면 기준가를 제시하지 않습니다.
- 조건부 후보가 3개 이상이면 시장·관련 뉴스, 매매 계획, 기술지표, 최근 10거래일 OHLCV를 모델에 전달합니다. 모델은 후보 선택과 정성 의견을 작성하며 종목·점수·중복을 검증합니다.
- 지수와 후보 종목의 최신 네이버증권 차트 종가를 같은 서비스의 일별시세 표와 대조합니다. 거래일이나 종가가 일치하지 않는 후보는 보류합니다. 지수 검증 실패 시 이전 파일을 유지합니다.
- 조건부 후보가 3개 미만이거나 Gemini 설정이 없거나 AI 응답이 유효하지 않아도 각 후보의 기술적 분석 리포트와 관련 뉴스는 열람할 수 있습니다.
- 사이트는 종목 선택, 20·60·90거래일 차트, 상세 리포트·기술지표 탭, 시장 뉴스와 고정 면책 문구를 제공합니다.

GitHub Actions는 매일 23:00 UTC(한국시간 다음 날 08:00)에 공개 사이트의 수집을 예약합니다. Windows 예약 작업도 로그인된 GitHub CLI로 같은 배포를 요청한 뒤 로컬 파일을 갱신합니다. 아침 배포는 08:30 이후에 게시하며, 그날 아침 자료가 이미 게시되어 있으면 중복 배포를 건너뜁니다. 실행 대기나 수집 지연이 있으면 사이트 반영도 늦어질 수 있습니다.

## 빌드 및 운영

```powershell
npm.cmd run build
$env:SNAPSHOT_PATH = Join-Path (Resolve-Path dist) 'latest.json'
.\.venv\Scripts\python.exe backend/pipeline.py --schedule
```

정적 서버의 루트를 dist로 지정합니다. 같은 호스트의 배치가 SNAPSHOT_PATH에 쓸 수 있어야 하며 다른 호스트나 CDN을 사용하면 배치 성공 후 latest.json을 웹 루트에 업로드해야 합니다. latest.json에는 캐시 재검증을 적용하세요. 재빌드 시 dist가 재생성되므로 마지막 성공 파일을 보존해 복원하거나 별도 저장소에서 제공합니다.

대시보드와 카드, 차트 컴포넌트는 src/main.jsx에, 반응형 스타일은 src/style.css에 있습니다. 샘플을 재생성하려면 가상환경에서 python backend/demo.py를 실행하세요.
